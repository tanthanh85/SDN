# Transition from Traditional Network to SDN Consideration

Open `index.html` in a browser to run the learner experience.

This folder contains a self-contained web page for the first PetroVale Energy scenario. Learners take the role of SDN Network Architect and move through 33 one-way architecture decisions as the company discovers brownfield network challenges, clarifies stakeholder concerns, evaluates candidate SDN domains, and considers transition principles.

The left-side menu opens reference content on the right:

- Questions
- Company Background
- Current Network Diagram
- Scenario Updates

Scenario updates are released progressively. The newest update appears at the end of the list and is highlighted with a different color.

Files:

- `index.html` - transition scenario web page.
- `styles.css` - layout, visual styling, and latest-context highlight.
- `app.js` - one-way decision flow, scenario update unlocks, scoring, missed-decision review, and explanations.
- `assets/` - local SVG diagrams for the petroleum network scenario.
- `assessment-source.md` - source notes for the scenario and question set.

Learners can only move forward. The final screen shows score, missed decisions, recommended answers, and explanations.
